# The Kingdom

A self-contained, time-aware daily ritual designed for mobile and desktop.

## Publish with GitHub Pages

1. Upload every file and the `icons` folder to the root of the `the-kingdom` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Open `https://YOUR-GITHUB-USERNAME.github.io/the-kingdom/` after GitHub finishes deployment.

## Install on Android

Open the live URL in Chrome, tap the three-dot menu, then choose **Install app** or **Add to Home screen**.

## Updating

Replace `index.html`, commit the change, and GitHub Pages will republish it. When changing cached files, update `CACHE_NAME` in `service-worker.js` from `the-kingdom-v1` to `the-kingdom-v2`, and so on.
